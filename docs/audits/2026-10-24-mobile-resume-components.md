# Mobile resume and component assessment

The service-worker client reloaded on every controller change, including first activation/client claim. Foreground transitions also checked updates without throttling. The fix requires an explicit Update action before reload and limits foreground update checks to once per hour. It never navigates on visibility changes. An optional tab-scoped scroll checkpoint restores the same route after a browser reload/discard, waits for content height, and yields to user input. No credentials or entitlement are stored in this checkpoint.

Better Auth already uses persistent one-year sessions with daily renewal. Implicit focus refetch is disabled in favour of a five-minute bounded background check. Existing signed-in UI and Convex subscriptions remain while a transient check fails; definitive missing/rejected sessions clear access. Backend entitlement enforcement remains authoritative. No cached browser entitlement grants access.

Component catalog reviewed: https://www.convex.dev/components . Better Auth remains installed. Official @convex-dev/rate-limiter 0.4.2 is wired to checkout creation, replacing the recent-payment scan with a bounded per-user token bucket. Three initial requests fit; sustained rate is three per minute. No added client subscription or provider fetch. Bulk feeds, model archives and evidence remain in R2. Accounts/access/small pointers remain in Convex. Action Cache (stores values in Convex), Aggregate (existing offline ledger aggregation), R2 component (existing private binding), Workpool/Workflow and AI agents are unnecessary for this change and were not installed.

Validation and deployment results are reported in the release response. Physical mobile OS process eviction cannot be prevented by a website; restored position is best effort once data renders. Session revocation, suspension, expiry and deliberate logout still revoke access.

Full Node suite at 229/229 passes, followed by two additional passing runtime regression tests for actual PWA/auth classes transpiled with mocked browser/provider boundaries (automatic-controller-change reload blocked; focus transient error retained and revoked session cleared). Build passes. Physical Android/iOS lifecycle testing remains a device acceptance check.
