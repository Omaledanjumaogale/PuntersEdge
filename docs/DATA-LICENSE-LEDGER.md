# Dataset and implementation licence ledger

Reviewed 19 October 2026. Account credentials are not evidence of every downstream redistribution permission. Raw corpora remain private in R2; this ledger does not grant rights that the source does not grant.

| Source | Verified permission / attribution | Application use | Boundary |
|---|---|---|---|
| Valuebetennis 2021-current CSV | Source expressly publishes CC BY 4.0, including commercial reuse with attribution: https://www.valuebetennis.com/donnees.htm | Private results-only Elo training and chronological match/first-set evaluation | Retain source licence snapshots, file SHA-256 and attribution in R2. No inferred service-point statistics. |
| UCI Tennis Major Tournament Match Statistics | CC BY 4.0; Jauhari, Morankar and Fokoue (2014), DOI 10.24432/C54C7K; https://archive.ics.uci.edu/dataset/300/tennis+major+tournament+match+statistics | Historical research benchmark only | 2013 tournament blocks cannot establish current-player performance or production validation. |
| API-Sports | User-authorized account, existing provider-export training | Private finished-game labels and authorized fixture analysis | Contract tier and subscription-product display/retention rights require account-holder review; no broad resale permission inferred. |
| The Odds API / OddsPapi | User-authorized accounts, existing quota pacing | Quoted odds when actually returned | Do not redistribute raw feeds or manufacture absent prices. Contract permissions require account-holder confirmation. |
| Eight reviewed GitHub prediction repositories | Individual pinned licence review in docs/research/FOOTBALL-UPSTREAM-REVIEW.md and NBA-UPSTREAM-REVIEW.md | Architecture research; independent implementations | No upstream datasets, pickles, model weights or executable notebooks imported. Stars and repository labels do not confer dataset rights. |
| Convex Better Auth schema | Apache-2.0, @convex-dev/better-auth 0.12.5 | Local compatible auth component schema | Licence retained at convex/betterAuth/LICENSE; schema extended for failedVerificationCount and lockedUntil from installed Better Auth plugin. |

Training and inference remain subject to source terms even when data is not displayed publicly. Non-commercial-only corpora are not approved for the paid membership product. New data sources require a recorded source, licence, acquisition date, fingerprint, permitted use and attribution before production adoption.
