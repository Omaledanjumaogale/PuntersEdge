# Administration and shared interface release

The desktop administration rail and hamburger menu use `ADMIN_NAV` from the shared navigation module. Overview, data operations, memberships and registry are addressable workspaces; the overview URL selects its workspace rather than maintaining a separate navigation list. Mobile workspace links scroll locally. The application retains its shared brand, theme tokens, action styles and profile identity.

Overview separates verified metrics from loading and unavailable states. Coverage links, pipeline status, governance links, scorecards, charts and contained table panels create a consistent hierarchy. Failed membership, refresh, export and registry actions expose persistent messages. Empty charts and tables describe missing records rather than inventing activity. Model registry supports real version/league searches, serving-state filters and existing protected import/activate/retire operations.

The diamond/key SVG is shared by the logo and browser/install assets. Decorative emoji retain accessible text labels. The console illustration disables its animation for reduced-motion preferences and the application's motion setting. Profile images come from synchronized authenticated account data; missing or failed images use initials. There was no demonstration-agent avatar in this checkout. WhatsApp functionality is excluded at the user's request; this repository had no queue or backend. Existing WhatsApp slip-sharing links, helper and promotional copy were removed; PDF exports remain.

Fixture markets use native accessible details/summary accordions. The first group opens initially; others are collapsed. Options within each group sort by descending model probability with deterministic ID tie-breaking. Filtering and sorting copy the selection array without changing the model or settlement data. Quotes, grades and notes retain their distinct meanings.
